# 3D-ресурсы: что временное и чем заменить

Прототип не использует внешние модели и текстуры — всё построено процедурно, без лицензионных рисков.
Это **временные объекты**, а не фотореализм. Для презентационной версии их нужно заменить.

| Что | Сейчас | Чем заменить | Требования |
| --- | --- | --- | --- |
| Мебель (19 типов: диван, кресло, кровать, шкафы, кухня, санфаянс, стиральная машина и др.) | Скруглённые примитивы, `Furniture.tsx` | GLB-модели | ≤ 20–50 тыс. треугольников на предмет, PBR (baseColor/normal/ORM), текстуры ≤ 2K, сжатие Draco/Meshopt, KTX2 |
| Внутренний и наружный блоки кондиционера | Примитивы, `Elements.tsx` | GLB конкретных моделей из каталога (ClimateCool) | Те же; модель привязать к `product_id` |
| Выключатель, датчики, хаб, щит, радиаторы | Примитивы | GLB | ≤ 5 тыс. треугольников |
| Ламинат, плитка, штукатурка, ткани | Текстуры, сгенерированные в браузере, `textures.ts` | Фото-PBR текстуры (CC0 или собственные) | baseColor + normal + roughness, бесшовные, 1–2K; цвет/фото ламината хранить в каталоге |
| Освещение | Лайтформеры drei | HDRI интерьера (локальный файл) | 1–2K `.hdr`, без загрузки с внешних CDN |
| Планировка №72 | Условная, `data/layouts/type-2k-68.json` | Реальные чертежи ЖК | Конвертер DXF/PDF → JSON планировки |

Порядок замены: положить файлы в `public/models` и `public/textures`, добавить загрузку через `useGLTF`
в соответствующем компоненте по типу мебели или `product_id`, оставив процедурную модель как запасной вариант.
