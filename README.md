# Академия кондиционирования — интерактивная 3D-платформа

Учебная платформа по бытовым сплит-системам: React + TypeScript, Three.js / React Three Fiber, GSAP, Zustand.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # сборка в dist/ (разделы грузятся отдельными чанками)
npm run build:single # всё в один HTML-файл: dist-single/index.html
```

## Что работает в прототипе

| Раздел | Что можно делать |
|---|---|
| 01 Квартира | 3D-квартира, вращение/масштаб, камеры «Обзор / Внутренний / Наружный / Фасад», вкл/выкл, охлаждение/обогрев, уставка и уличная температура, потоки воздуха (частицы с плавучестью), тепловая карта у пола, датчики в зонах, клик по блокам, трассе, дренажу, окну, пульту |
| 02 Устройство | Детальная модель внутреннего (9 узлов) и наружного (9 узлов) блоков, «Разобрать / Собрать», выбор, изоляция детали, компрессор в разрезе + 2D-анимация ротационного компрессора, прохождение воздуха через теплообменник с изменением температуры |
| 03 Цикл | Анимированная схема: 5 этапов, пауза, скорость, пошагово и автопоказ, охлаждение и обогрев (4-ходовой клапан), цвет = температура, размер частицы = фаза, давления R32, энергобаланс |
| 04 Мощность | Визуальная комната, которая перестраивается по параметрам; поэлементный расчёт теплопритоков, кВт, BTU, класс 7–24k, потребление из сети, сравнение с «1 кВт на 10 м²», предупреждения о необходимости инженерного расчёта |
| Тесты | После каждого раздела; режим «Ученик-монтажник» добавляет вопросы. Прогресс — в localStorage |

Настройки: режим покупатель/монтажник, качество графики, уменьшенная анимация, 2D-схемы вместо 3D (включаются автоматически без WebGL).

## Архитектура

```
src/
  core/            общее, без React-компонентов сцены
    modules.ts     реестр разделов (точка расширения)
    store.ts       состояние, прогресс, настройки, сохранение в браузере
    load.ts        расчёт холодильной нагрузки (все коэффициенты — константами)
    roomSim.ts     учебная модель температурного поля комнаты
  three/           переиспользуемые 3D-модели
    splitParts.tsx реестр деталей сплит-системы (позиция, вектор разлёта, компонент)
    primitives.tsx рёбра теплообменника, трубы
  ui/              оболочка, навигация, стили
  modules/<id>/    независимые разделы: home, device, cycle, calculator, quiz, roadmap
```

Правило: модули не импортируют друг друга. Новый раздел = папка в `modules/`, запись в `core/modules.ts` и строка в `App.tsx`. Модели блоков из `three/splitParts.tsx` уже используются в двух разделах и подойдут для монтажного симулятора.

## Оговорки по инженерной части

- Температуры и давления в схеме цикла — типичные ориентировочные для R32; реальные зависят от модели и условий.
- Расчёт нагрузки — учебный поэлементный метод на пиковый час, не проектная методика.
- Монтажные параметры (длина трассы, перепад, моменты затяжки, зоны обслуживания) не задаются универсально — только из документации производителя.
- Симуляции не являются инструкцией для самостоятельных работ с электричеством, высотой, давлением и хладагентом.
