# 3D Home Academy — интерактивная цифровая квартира №72

Самостоятельное веб-приложение для экосистемы **E-Shanyraq**, **«Города мастеров»** и **Naidu.kz**.
Жилец (или мастер) открывает 3D-модель своей квартиры, нажимает на пол, кондиционер или выключатель,
изучает устройство, выбирает комплектацию, считает смету, заказывает услугу и сохраняет историю работ в цифровом паспорте.

```
3D-квартира → элемент → академия → сравнение вариантов → «Найти дешевле» → смета → заказ → цифровой паспорт
```

> **Демо-статус.** Планировка квартиры №72 — условная (чертежи ЖК не загружены). Все цены — тестовые числа
> демо-каталога и помечены в интерфейсе. Инженерные сети в «Рентгене» — условная схема.

## Быстрый старт

Нужен Node.js 20+.

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm test           # 42 автотеста (каталог, сметы, академии, планировки, паспорт, интеграции, сервер)
npm run build      # сборка в dist/
npm start          # сервер для VPS: статика + /api/catalog, http://localhost:8080
```

На Windows те же команды выполняются в PowerShell из папки проекта.

## Что внутри

| Модуль | Где | Что делает |
| --- | --- | --- |
| 3D-сцена | `src/apartment/scene` | Квартира на React Three Fiber: стены с проёмами, окна, двери, полы с текстурами, мебель, PBR-освещение, мягкие тени, автоматический «срез» наружных стен, камера 360° |
| Планировки | `data/layouts`, `src/apartment/layout.ts` | Геометрия типовой планировки отдельно от данных квартиры; зеркальные квартиры; индивидуальные изменения; версии |
| Иерархия | `data/complexes` | ЖК → корпус → подъезд → этаж → квартира → помещение → элемент |
| Ядро академий | `src/core/academy.ts`, `src/academies/index.ts` | Единый контракт; новая академия добавляется без изменения ядра |
| Академии | `src/academies/{flooring,climate,smarthome}` | Напольные покрытия, кондиционирование, умный дом: уроки, калькуляторы, комплектации |
| Каталог | `src/catalog`, `data/catalog/*.csv` | `CatalogProvider`: `DemoCatalogProvider` и `GoogleSheetsCatalogProvider`; проверка единиц, дублей, пропусков |
| Смета | `src/estimate/engine.ts` | Материалы / оборудование / расходники / работы / доставка; кратность упаковок; нормы расхода из таблицы |
| Поиск цен | `src/integrations/naidu` | `PriceComparisonAdapter`, демо-адаптер, сравнение совместимости и итоговой стоимости |
| Заказы | `src/integrations/gorodmasterov` | Демо-процесс без оплаты; цены фиксируются в заказе; статусы по ролям |
| Цифровой паспорт | `src/passport` | Квартира → помещение → категория → запись; фото и PDF в IndexedDB; права жильца, мастера, администратора |
| E-Shanyraq | `src/integrations/eshanyraq` | Переход из кабинета, роли, совместимость с `passport_records` |
| Сервер | `server/` | Статика, `/api/catalog` из Google Таблицы через сервисный аккаунт, кэш, `/api/health` |

## Режимы

* **Моя квартира** — выберите комнату (кнопки сверху или касание пола), затем объект по метке с названием. Внизу появится плашка «Как устроено / Цена и варианты». Все объекты списком — кнопка «Объекты».
* **Рентген** — полупрозрачные стены и условные трассы: электрика, вода, канализация, отопление, вентиляция, кондиционирование, умный дом. Пунктир = условно, сплошная = проект, с точками = подтверждено.
* **Энциклопедия** — нажатие на объект сразу открывает объяснение «как устроено».
* Переключатель **«Для мастера»** показывает технические детали; роль (Жилец / Мастер / Администратор) переключается в шапке (в демо).
